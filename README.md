# Forecasting_flight_departure_delays
This project aims to forecast the next-day departure delay for the flight departure delays. The report is done on R, showing different models to achive the same purpose, based on kaggle data.
This project is meant to show a beginner data analyst or data scientist how to manipulate time-series data, showing different models and how to choose among them. This project was done not only by me, but with the help of other 2 people as the main part of a university class.

Data: "Flight_Data.csv"
The dataset was obtained from Kaggle and contains 484,551 commercial US flights recorded between January 1st and June 30th, 2019. 

The code for analysis is "Forecasting_Project.R"

In the file "Project_Report.pdf" is the main document of the project that explain everything in detail.

The file "Project_PPT.pdf" instead is the presentation I personally used to sum up my work with the professor.
